## Logos (`assets/icons/`)

The SVG files come from [Simple Icons](https://simpleicons.org) (CC0 1.0). The `.a` files are 192x192 alpha masks rendered from those SVGs.
Simple Icons is public domain, but the logos themselves are trademarks of their owners: Fedora, Ubuntu, Debian, Arch Linux, openSUSE and Linux Mint.
Sail shows them only to label the operating system a boot entry starts. It is not affiliated with or endorsed by any of these projects.
The Windows tile is four plain blue squares drawn by code, not the Microsoft logo.
